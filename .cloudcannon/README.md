# Editing this blog

This site is a personal blog: posts, an about page, a projects page, and lists of posts by tag.

## Pages

The home, projects, blog, tags and about pages.

- **Home and Projects** are built from sections. Open the page, then add, remove or drag sections in the sidebar: a page header, a list of recent posts, and a grid of projects.
- **Blog and Tags** show lists that update on their own when posts change. You can change their heading and description.
- **About** shows an author's profile. Choose which author in the sidebar; edit the profile itself under Authors.

Use **+ Add** to create a new page. A **Page Builder** page is made of sections. A **Page** is a title and text. A new page previews as the Projects page until the site has rebuilt with it.

## Blog

Each post has a title, date, tags, summary and text.

- Create a post with **+ Add**. It opens in the text editor.
- Turn on **Draft** to keep a post off the live site. Drafts don't have a preview page.
- **Post layout** changes how a post looks: Standard (with an author sidebar), Simple, or Banner (with the first image across the top).
- Pick tags from the list, or type a new one. To offer a tag on every post, add it to the tag list under Site settings.
- Posts can sit in a folder to group a series. The folder name becomes part of the post's address.

## Authors

The people who write posts. A post shows its authors' name, photo and social link. The About page shows one author's full profile and the text written below it.

## Site settings

- **site** — the site title, header title, description, contact email and default link preview image
- **navigation** — the links in the header menu, in order
- **social** — the social icons in the footer, in order
- **tags** — the tags offered when tagging a post

## Rich text components

In a post's text you can insert:

- **Table of contents** — lists the post's headings
- **Image gallery** — a grid of images
- **Video** — a video player for a .webm file
- **Equation** and **Inline equation** — maths written in LaTeX
