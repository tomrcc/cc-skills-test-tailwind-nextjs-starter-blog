# Editing the blog

This is a personal blog: posts, author profiles, a home page and a projects page. Everything you change here is saved back to the site and shows up on the live site once it's published.

## Pages

The home page, the projects page and the About page. Each page is a stack of sections you can add, remove and drag into a new order:

- **Page header**: the big heading and the line of text under it
- **Latest posts**: the newest blog posts, with how many to show
- **Project grid**: project cards, each with a title, description, image and link
- **Author profile**: an author's photo, details and bio, picked from Authors. Change the details in the author's own file.
- **Newsletter sign-up**: the subscribe form. It works on the live site only; in the editor preview it can't send.

Use **+ Add** to create a new page. A **Page** is built from sections. A **Text page** is a heading and written content. A new page shows the projects page in the preview until the site has rebuilt.

## Blog

Every post, written in the Content Editor. Set the title, date, tags, summary and authors in the sidebar. Turn on **Draft** to keep a post off the published site; drafts can't be previewed as a page.

Inside a post, use the component button in the toolbar to add a table of contents, a newsletter sign-up, a photo gallery, a video, a photo credit, an alert box, footnotes or citations.

The post "Deriving the OLS Estimator" is full of maths formulas, so it opens in the Data Editor and its text is edited in the Source Editor, where the formulas stay exactly as written.

## Authors

The people who write posts. Pick them in a post's **Authors** field. The About page shows the author picked in its Author profile section.

## Settings

- **Site**: the site name, header title, description, contact email, social links and the footer credit
- **Navigation**: the links in the header menu
- **Tags**: the list of tags you can pick on a post. Add a tag here first, then choose it on the post.
