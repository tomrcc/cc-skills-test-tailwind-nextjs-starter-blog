## Decisions and why

- **Clean state includes `.contentlayer/` and the Yarn cache** — CloudCannon's first build starts from a fresh clone with neither; `preserved_paths` keeps only `node_modules/` and `.next/` on later builds
- **`/blog/page/3/` left as a 404** — the starter counts drafts when listing pagination params; changing it changes the starter's routes and isn't a migration issue
- **Hosting checks only in the handoff** — everything that can run locally ran above; the handoff asks only what the CloudCannon build environment, the Visual Editor and hosting can answer
